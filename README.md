# نظام إدارة المخازن والمخزون المتقدم

## 📋 نظرة عامة

نظام متكامل لإدارة المخازن والمخزون يعمل على شبكة محلية (LAN) باستخدام:
- **الواجهة الأمامية**: HTML5, CSS3, JavaScript, Bootstrap 5
- **الخلفية**: PHP 8.x مع REST API
- **قاعدة البيانات**: MySQL/MariaDB

## 🚀 متطلبات التشغيل

### المتطلبات الأساسية
- **خادم ويب**: Apache 2.4+ أو Nginx
- **PHP**: الإصدار 8.0 أو أحدث
- **MySQL**: الإصدار 5.7+ أو MariaDB 10.3+
- **المتصفح**: Chrome, Firefox, Edge, Safari (أحدث الإصدارات)
